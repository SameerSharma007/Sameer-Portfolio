// 01 · origin log

How a page became a craft

Every site I ship is a stack of small decisions. This is how mine layered up — one chapter at a time.

CH.01
Hello, World
2016 · the spark

Hello, World

It started with a school project page and a CSS trick stolen from a forum. I hand-coded my first site in Notepad, uploaded it over painfully slow Wi‑Fi, and waited for the browser to blink back. The moment it did — with my name on it, live on the internet — something clicked that never un-clicked.

index.html
<body onload="alert('hi, world')">
2017–18 · the obsession

Markup & Paint

I fell for CSS the way people fall into photography — slowly, then all at once. Flexbox felt like magic. A well‑tuned box-shadow felt like money. I rebuilt my own homepage four times in a month, each one "final", none of them actually final.

styles.css
.btn:hover { transform: translateY(-2px); }
2019 · pages that think

The Logic Layer

Then the pages started thinking. My first React app taught me that state is a promise you make to yourself — and the DOM keeps score of every broken one. I deleted more code than I wrote, and the apps got better for it.

app.tsx
useEffect(() => { syncCart(); }, [cart]);
2020–22 · under the hood

Systems Thinking

Frontend stopped being enough. I learned Postgres by breaking it, Node by scaling it, and Docker by losing a weekend to it. Deploys became boring — which is exactly the goal. Boring means reliable, and reliable means people trust you with their product.

deploy.sh
docker compose up -d && flyctl deploy --strategy blue-green
now · the standard

Craft & Performance

Today I obsess over the last 100 milliseconds and the first impression. Motion with meaning, budgets that hold, interfaces that respect the reader's thumb and attention. The web is a medium — I'm still learning its grammar.

motion.css
@media (prefers-reduced-motion: reduce) { /* respect the reader */ }
